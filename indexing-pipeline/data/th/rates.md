# อัตราค่าห้องพัก

## ราคาห้องพัก
อัตราค่าห้องพักต่อห้องต่อคืนดูได้จากระบบจองเท่านั้น เอกสารนี้ไม่ได้ระบุตัวเลขไว้
เพราะราคาปรับเปลี่ยนได้ และตัวเลขที่เขียนค้างไว้ในเอกสารจะขัดกับราคาที่ใช้จองจริง
ราคาเท่ากันทุกวัน ไม่ว่าจะเป็นวันธรรมดาหรือวันหยุดสุดสัปดาห์ ไม่มีการบวกราคาช่วงวันหยุด
ราคาคิดเป็นรายห้อง ไม่ได้คิดเป็นรายคน

ราคาห้องพักไม่รวมอาหารเช้า เพราะรีสอร์ทไม่มีบริการอาหารเช้า
ภาษีมูลค่าเพิ่ม (VAT): <<รอเติม: ราคาห้องพักรวมภาษีมูลค่าเพิ่มแล้วหรือยัง>>

## ค่าใช้จ่ายเพิ่มเติม
เตียงเสริม คืนละ 200 บาทต่อเตียง ขอได้ทุกห้อง คิดเพิ่มจากค่าห้องพัก
ค่าเตียงเสริมคิดตามจำนวนเตียงที่ขอและจำนวนคืน ไม่ได้คิดตามจำนวนห้อง
วิธีคิดยอดรวม: (ค่าห้องต่อคืนจากระบบจอง x จำนวนห้อง x จำนวนคืน) + (200 x จำนวนเตียงเสริม x จำนวนคืน)
ค่าใช้จ่ายอื่นนอกเหนือจากนี้: <<รอเติม: มีค่าใช้จ่ายอื่นอีกหรือไม่ เช่น ค่าเช็คเอาท์ช้ากว่า 12.00 น.>>

## การชำระเงินและมัดจำ
การจองจะสมบูรณ์เมื่อชำระเงินมัดจำห้องพักแล้วเท่านั้น
เงินมัดจำ 200 บาท
โอนเข้าพร้อมเพย์ (PromptPay) หมายเลข 081-599-3128
หมายเหตุ: หมายเลขพร้อมเพย์ 081-599-3128 เป็นคนละหมายเลขกับเบอร์ติดต่อ 081-598-1199
แต่ทั้งสองหมายเลขเป็นของรีสอร์ท ถ้าไม่แน่ใจโทรยืนยันก่อนโอนได้ที่ 081-598-1199
ยอดคงเหลือชำระในวันเช็คอิน

รีสอร์ทรับชำระเงินด้วยการโอนเท่านั้น ไม่รับเงินสดและไม่รับบัตรเครดิต
กำหนดชำระมัดจำ: <<รอเติม: ต้องโอนมัดจำภายในกี่ชั่วโมงหลังจอง>>
ใบเสร็จ/ใบกำกับภาษี: <<รอเติม: ออกให้ได้หรือไม่>>

## สิ่งที่ไม่รวมในราคาห้องพัก
ค่าห้องพักเป็นค่าห้องอย่างเดียว ไม่รวมอาหารเช้าและไม่รวมเตียงเสริม
รีสอร์ทไม่มีบริการอาหารเช้า ไม่มีห้องอาหาร และไม่มีรูมเซอร์วิส
