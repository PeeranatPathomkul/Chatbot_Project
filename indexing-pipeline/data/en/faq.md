# Frequently Asked Questions (FAQ)

> Note for content editors: this file is meant to overlap with the other files.
> Guests ask in casual language ("can I bring my dog?"), which matches an FAQ
> entry far more closely than a formally worded policy heading. Having both
> phrasings indexed means the chatbot finds the answer either way.
>
> When adding questions, keep the "Q: ... / A: ..." format and leave a blank
> line between each pair — the pipeline uses blank lines as chunk boundaries.
> Keep this file consistent with data/th/faq.md.
