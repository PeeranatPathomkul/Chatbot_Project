# Room Types

Poonsuk Resort has 6 rooms in total. Each room is a separate small house.
There are 2 room types: twin-bed rooms (twin) and single-bed rooms (single).
Every room is the same size — 16 square metres (4 x 4 metres).
Which room number is which type, how many guests it sleeps and the nightly rate are all
available from the booking system. This document does not say which room is which type,
because staff can change that in the booking system.

## Twin-Bed Rooms (twin)
These are the rooms whose type is twin in the booking system.
Each has two separate beds, ideal for friends or families who prefer separate beds.
Room size: 16 square metres (4 x 4 metres).
Sleeps as many guests as it has beds, plus one more if an extra bed is requested.

## Single-Bed Rooms (single)
These are the rooms whose type is single in the booking system.
Each has one large bed, ideal for couples or two guests.
Room size: 16 square metres (4 x 4 metres).
Sleeps as many guests as it has beds, plus one more if an extra bed is requested.

## All Rooms
The resort has 6 rooms: P1, P2, P3, P4, F1 and F2.
Which type each room number is (twin or single) is available from the booking system.
Every room is a detached house with its own private bathroom and parking close by.

## In-Room Amenities
All rooms have the same amenities:
air conditioning
free high-speed Wi-Fi
a private bathroom inside the room, with a water heater
television
refrigerator
electric kettle with complimentary instant coffee sachets
towels, soap and shampoo
hairdryer
a table and chairs for relaxing in the room

## Extra Beds and Children
An extra bed can be added to any room for 200 THB per bed per night.
This is charged on top of the room rate, which is available from the booking system.
One extra bed can be added per room, letting the room sleep one more guest.
Please request the extra bed when you book.

The resort charges per room, not per person, so there is no separate child policy.
Children stay at no additional cost as long as the total number of guests stays within
the room's capacity. If you need an additional bed, the 200 THB per night extra bed fee applies.

## Not Provided in the Rooms
Breakfast is not provided — the rate covers the room only.
There is no room service.
Smoking is not permitted inside the rooms.
Pets are not allowed.
