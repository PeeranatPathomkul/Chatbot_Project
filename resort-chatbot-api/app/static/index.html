พูนสุข รีสอร์ท สะเดา กำลังตรวจสอบ…
พิมพ์คำถามด้านล่าง หรือกดคำถามตัวอย่างเพื่อเริ่มทดสอบ

กรอบสีส้มคือคำตอบที่บอท ปฏิเสธ เพราะไม่มีข้อมูลในคลัง — ไม่ใช่ข้อผิดพลาด แต่เป็นพฤติกรรมที่ต้องการ ให้ดู answered เป็นหลัก ไม่ใช่ score เพราะคำถามที่ระบบไม่มีคำตอบก็ได้ score สูงราว 0.83 พอ ๆ กับคำถามที่ตอบได้
